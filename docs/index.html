epson-usb-display

Use an Epson projector's USB-B “USB Display” port on Linux. The projector appears in GNOME as a normal monitor you can extend onto or mirror. No HDMI or VGA cable needed.

Download (.zip) View on GitHub

Install

git clone https://github.com/dixonSolutions/epson-usb-display.git
cd epson-usb-display
./install.sh

Connect the USB-B cable, pick the USB Display source on the projector, and a new 1024×768 monitor shows up in Settings → Displays.

Requirements

  • GNOME on Wayland (tested on GNOME 50, Fedora 43)
  • Python 3 with PyGObject and dbus-python, GStreamer with the PipeWire plugin
  • An Epson projector that enumerates as USB 04b8:061b (EB-X04, EB-X130, EB-X300, VS340, …)

How it works

The projector pretends to be a CD-ROM. Epson's Windows driver sends the picture as vendor SCSI commands to that CD-ROM. epson-usb-display does the same from userspace through libusb. It asks GNOME for a virtual monitor, captures it through PipeWire, and streams the changed rows to the projector as raw 24-bit bands. Small changes are near-instant; full-screen changes run at about 9 fps.

The full reverse-engineered protocol is documented in PROTOCOL.md.
